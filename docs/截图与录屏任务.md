## 状态规则

| 状态 | 含义 |
| --- | --- |
| 已完成 | 交付与验收均已完成，并有可定位证据 |
| 待开始 | 前置条件满足，可以领取，但尚未执行 |

- 开始任务时更新状态、负责人和当前步骤；进入“待验收”时写明验证方式，通过后改为“已完成”并补充证据，同时检查下游任务能否改为“待开始”。
- 构建通过、浏览器测试、真机实测分别记录，不能相互替代；未覆盖的场景标明“未验证”。
