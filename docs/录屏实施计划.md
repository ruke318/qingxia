# 基础录屏实施计划

> 执行方式：使用子代理执行技能逐项实现，任务完成后审查规格与代码，最后统一验证；用户已授权开始实现，无需在任务之间再次确认。

**目标：** 交付区域、整屏、窗口录屏，默认静音，可选系统声音和麦克风，鼠标点击圆圈直接录入视频，并支持停止、预览、保存和复制文件。

**架构：** Rust 宿主管理录制会话、原生流、窗口和临时文件；React 负责选区、控制条和预览。使用 `SCStream + SCRecordingOutput` 写 MP4，原生对象持有到文件完成回调；沿用现有截图的屏幕快照与坐标规范。

**技术栈：** Tauri 2、Rust、objc2 0.6、ScreenCaptureKit 0.3.2、React、TypeScript。

**规格：** [截图与录屏计划](截图与录屏计划.md) 第 5 节；[截图与录屏任务](截图与录屏任务.md) SC31～SC34。

## 全局约束

- 应用最低 macOS 13，截图与录屏功能要求 macOS 15；不提高整个应用版本下限。
- 每次新录屏系统声音与麦克风均默认关闭，声音选择只对本次生效；首次开启麦克风才请求权限。
- 显示光标，点击圆圈默认开启，使用 `showMouseClicks` 与 BGRA；首版使用 SDR、H.264、MP4，采集更新频率上限为 30 帧。
- 排除轻匣全部界面及自身声音，包括录制期间新打开的窗口；不允许插件主动读取屏幕或视频文件。
- 同时只允许一个截图或录屏会话；录屏进行中唤起主面板与失焦不结束录制。
- 所有停止入口幂等，预览和输出只在文件完成回调后开放；退出先收尾再退出。
- 原生回调通过会话编号拒绝迟到事件，UI 操作调度到主线程；不得提前释放流、输出或代理。
- 视频资源校验预览窗身份，支持 Range 拖动播放，不经 Base64 传输。
- 所有新增注释、文档、界面文本、错误提示、测试描述使用简体中文。
- 不提交、不推送、不安装覆盖已有应用；保留原目录介绍页文件。开发与验证在隔离工作区完成，最后同步改动回原目录。

## 固定接口

```ts
type RecordRect = { x: number; y: number; width: number; height: number };
type RecordTarget = { kind: "region" | "display" | "window"; display: number; window?: number; rect: RecordRect };
type RecordOptions = { systemAudio: boolean; microphone: boolean; showClicks: boolean };
type RecordCandidate = RecordRect & { id: number; name: string };
type RecordContext = {
  role: "select" | "control" | "preview" | "border";
  session: number;
  display?: number;
  screen?: number;
  scale?: number;
  image?: string | null;
  windows?: RecordCandidate[];
};
type RecordStatus = {
  phase: "preparing" | "selecting" | "starting" | "recording" | "finalizing" | "preview" | "failed";
  elapsed: number;
  duration: number;
  fileSize: number;
  error: string | null;
  savedPath: string | null;
  videoUrl: string | null;
};
```

宿主在 `capture.html` 注入 `window.__QINGBOX_RECORD__: RecordContext`，录屏窗口标签前缀为 `record-`，角色包含在标签中。保留原截图、贴图的分发方式。

命令全部检查实际窗口身份与会话编号，参数与返回值如下：

| 命令 | 参数 | 返回值 | 允许调用者 |
| --- | --- | --- | --- |
| `start_recording_command` | 无 | 无 | 主入口 |
| `record_start` | `{ session, target, options }` | 无 | 当前会话选区窗 |
| `record_cancel` | `{ session }` | 无 | 当前会话选区窗 |
| `record_status` | `{ session }` | `RecordStatus` | 当前会话选区、控制、预览窗 |
| `record_stop` | `{ session }` | 无 | 当前会话控制窗 |
| `record_save` | `{ session }` | `string | null`，取消保存返回 null | 当前会话预览窗 |
| `record_copy` | `{ session }` | 无 | 当前会话预览窗 |
| `record_reveal` | `{ session }` | 无 | 当前会话预览窗 |
| `record_close` | `{ session }` | 无 | 当前会话预览窗，用户明确舍弃或已完成保存 |

时间字段单位为秒；文件大小为字节；矩形为显示器内以左上为原点的逻辑点。窗口模式通过真实窗口 ID 定位，不能把矩形裁剪冒充窗口录制。页面每 500 毫秒读取状态，计时从录制成功回调开始。预览窗监听定向事件 `record-close-requested`，将原生关闭按钮与页面关闭按钮接入同一确认流程；已保存可直接关闭，未保存需明确舍弃，重复请求只显示一次确认。
