## 生成提示词

用途：logo-brand。为 macOS 原生效率启动器「轻匣 QingBox」设计并输出一个可直接用于应用程序的精致图标，而不是图标展示板。应用功能是快捷键搜索和插件工具箱，气质轻巧、安静、专业，符合苹果桌面审美。

画面：一个正方形 1024×1024 的应用图标资产；画布四角和主体外部必须是真正透明。中心是近白色微暖瓷质圆角方形底板，标准 macOS 图标的大圆角比例，占画布约 86%，四边等距留白。底板仅有非常轻的上方高光和柔和短阴影。

标志：底板中央只有一枚大胆清晰、原创的「轻匣」符号：一个微微开启的圆角小匣子。用极简的深青蓝色 U 形盒身和一片向上轻轻悬起的浅青色盒盖构成；盒盖与盒身间有一条明确、优美的留白，像一键唤起的搜索入口。整体正面为主、只有极轻微的空间厚度，视觉重心精确居中。盒身要厚实干净，不要线稿。盖子可以有微弱磨砂玻璃光泽。白色负空间形成盒子的内部。主符号占底板约 62%，轮廓在 32 像素小尺寸依然可辨认。

材质与配色：瓷白、深青蓝、克制的冰青色高光；清晰的明暗关系，柔和但不发灰。像精心设计的 macOS 原生生产力软件图标，成熟、简洁、有记忆点。
严格不要：文字、字母、汉字、数字、水印、品牌标识、放大镜、齿轮、魔法棒、星星、闪电、多个小物件、网格、多方案、场景、桌面截图、外层背景、过度透视、夸张渐变和霓虹光。输出单个居中完整图标，透明背景。
