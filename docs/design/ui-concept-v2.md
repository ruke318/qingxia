## 完整生成提示词

用途：ui-mockup。为 macOS 快捷工具「轻匣」重新设计一张高保真 UI 概念图。用户已明确否定传统应用窗口风格。这次必须彻底采用 macOS Spotlight 聚焦搜索式的浮动面板交互与真实通透的毛玻璃美学。

最核心硬性要求：
1. 这不是常规应用窗口，绝对没有标题栏，没有红黄绿窗体按钮，没有顶部品牌栏，没有侧边导航，没有工具栏。没有窗口顶部的应用名称。没有“仪表盘”“管理后台”结构。
2. 默认态就是由全局快捷键呼出的一个全局输入框。进入某个插件后，同一个浮动面板向下展开插件内容。始终保持轻盈悬浮，不变成传统软件窗口。
3. 材质是真正可感知的 macOS 磨砂半透明玻璃：桌面壁纸的颜色与轮廓经高斯模糊明显透过面板。绝对不要画成不透明白色卡片。文字保持清晰高对比。
4. 不要沿用上一版三个传统软件窗口的排布，不要出现上一篇绿色按钮、文件夹插图或大块白色区域。

画布与构图：
一张横向约 16:10 高分辨率设计图，只有两个界面状态，左右并列，正面、无透视。背景是一幅精致的 macOS 风格抽象桌面壁纸：柔和的大尺度墨蓝、雾紫、淡桃色流动曲面，色调优雅而低饱和，不是星空或科幻。避免虚假的系统菜单栏或 Dock，主角只有两块悬浮玻璃面板。
左侧占画幅约 40%，展示默认唤起状态。右侧约 50%，展示进入插件后的展开状态。两块面板中线对齐、四周留白充足，不重叠。画布左上角只有很小的「轻匣 / 界面概念 02」，左状态上方很小的「01  快捷键唤起」，右状态上方很小的「02  进入插件」。这些是画布注释，绝不出现在面板内部的标题栏。

左侧默认态：
只有一个细长的圆角浮动搜索框，类似 macOS Spotlight，宽高比约 6:1，20 至 24px 圆角，1px 极细半透明亮边，柔和深阴影。玻璃偏深烟灰蓝，但有清晰的背景透色，整块很通透。
左边一个纤细放大镜图标，输入占位文案「搜索任何内容…」，使用精致易读的中文无衬线字体，字号自然，不粗大。输入框右端仅一枚低对比小键帽「⌘ K」。不出现应用 logo、不出现设置齿轮、不出现插件列表、不出现底栏。
面板下方画布留白处以很小的低对比文字注明「一个入口，随时唤起」。

右侧插件态：
同样材质、同样圆角与边缘处理的浮动玻璃面板，宽约左侧的 1.15 倍，高约 510px，完全没有窗体标题栏和红黄绿按钮。
面板的第一行本身就是搜索输入：左边一枚轻量的返回尖括号，接一枚内嵌的小胶囊「剪贴板」，后面是输入占位文字「搜索历史内容…」，右边一枚小键帽「Esc」。这些元素全部在同一行，不另占标题栏。
输入行之下极细半透明分隔线。下一行是低调文字标签「全部  文本  图片  文件」，仅「全部」有很轻的半透明选中底色，不要绿色大块，不要宽大分段控件。
主体是一列精致的紧凑记录列表，保持 Spotlight / Raycast 式命令面板的信息密度：
第一行被轻微高亮，使用半透明乳白背景，左有极简文档细线图标，主文字「接口返回示例」，下面一行等宽预览 { "code": 200, "message": "成功" }，右边小字「刚刚」。
第二行左有一个很小的图片缩略图，主文字「界面参考.png」，副文字「图片 · 1440 × 900」，右边小字「5 分钟前」。
第三行左有极简文件线条图标，主文字「项目资料」，副文字「3 个文件」，右边小字「12 分钟前」。
第四行左有极简文字图标，主文字「周一的会议备忘」，副文字「确认插件入口与快捷键交互」，右边小字「28 分钟前」。
这些记录直接坐落在同一整块半透明玻璃上，没有卡片堆叠，没有第二列详情区，没有大代码框，没有独立白色内容容器。
面板最底部仅一条非常纤细的提示行，不形成工具栏：左侧淡色「↑ ↓ 选择」，右侧「↵ 复制」与一个低调的「⌘ ,」键帽用于插件设置入口。不画完成、保存或复制的大按钮。

视觉气质：
精致、克制、像 macOS 原生系统的一部分。优先字体节奏、精确对齐、清晰图标、微妙高光与自然真实的背景模糊。没有营销装饰、没有漂亮但不实用的大标题，不使用绿色主色或高饱和控件。所有用户可见文案均为准确简体中文，保留必要快捷键与 JSON 语法。两个状态必须明显属于同一个会展开的输入面板。
