# 截图与录屏计划

日期：2026-10-08。方案版本：1.0。状态：方案定稿，尚未开工。

来源：用户需求（截图可画框、标注步骤、打马赛克；录屏可选区域），经 Codex 评审（2026-10-08）后整理。第 1 节中标“建议值”的决策用户尚未逐项确认，开工前如有调整，直接修订本文。

## 0. 需求范围

- 截图：选区或选窗口，原地标注（框、箭头、画笔、文字、步骤序号、马赛克），复制或保存。
- 录屏：同样可选区域、窗口或整屏，录制后预览、保存。
- 不做：插件读取屏幕的开放接口、非 macOS 平台、长截图（单独评估）。

## 1. 决策

| 项目 | 决定 | 说明 |
| --- | --- | --- |
| 形态 | **宿主内置功能** | 覆盖窗、捕获会话、录制控制都由宿主管理，不依赖插件 iframe 的生命周期。搜索入口为内置命令“截图”“录屏”，设置放在设置页 |
| 插件开放 | **一期不开放** | 插件权限来自清单自行声明，本地插件还能覆盖同 ID 内置插件，声明一个权限字符串不足以授权读取屏幕。以后如开放，只提供“请求用户交互式截图”并返回结果标识，不提供冻结全屏、连续帧或任意区域 |
| 系统版本 | **功能基线 macOS 15** | `SCScreenshotManager` 需 14+，`SCRecordingOutput` 与麦克风捕获需 15+。应用最低版本保持 13，截图、录屏在运行时检查版本，低版本搜索入口提示“需要 macOS 15 或更高版本” |
| 标注方式 | **原地标注**（建议值） | 微信截图式：选区下方出现工具栏，直接在选区上画。录屏结束使用独立预览窗 |
| 默认快捷键 | **截图 ⌥⇧A，录屏 ⌥⇧R**（建议值） | 进入快捷键页“轻匣”分组，可修改。截图默认值在一期首次初始化时写入（同剪贴板的 ⌥⇧V 做法），被占用时该行显示原因；录屏默认值到二期上线时才写入。避开系统 ⌘⇧3/4/5 |
| 保存位置 | **系统保存对话框，用户自选**（2026-10-08 按用户反馈调整） | 默认打开上次保存的目录，首次为“图片”；文件名默认带时间 |
| 遮盖 | **马赛克 + 实色遮盖** | 马赛克可能被推测还原，敏感内容建议用实色遮盖；导出时都真正改写像素 |
| 录屏暂停 | **首版不做** | `SCRecordingOutput` 没有暂停接口，移除输出即结束文件，录制中更新配置也可能结束录制 |
| 截图选窗口的语义 | 按窗口边界裁剪冻结画面 | 保留当时的遮挡；跨屏窗口只取当前屏部分。与录屏“窗口被遮挡照录”是两种语义，界面文案区分 |

## 2. 架构

### 2.1 模块划分

| 部分 | 位置 | 职责 |
| --- | --- | --- |
| 捕获会话 | `src-tauri/src/capture/mod.rs` | 会话状态机、防重复触发、与主面板的隔离、宿主命令 |
| 权限 | `src-tauri/src/capture/permission.rs` | `CGPreflightScreenCaptureAccess` 检测；仅在用户主动操作后 `CGRequestScreenCaptureAccess`；拒绝时引导打开系统设置 |
| 覆盖窗 | `src-tauri/src/capture/overlay.rs` | 每块屏幕一个覆盖窗的创建、层级、Spaces、焦点、销毁 |
| 截图 | `src-tauri/src/capture/screenshot.rs` | 取各屏快照与窗口列表（含层叠顺序）、坐标换算、写剪贴板与文件 |
| 录屏 | `src-tauri/src/capture/record.rs`（二期） | `SCStream` + `SCRecordingOutput`、自身窗口排除、收尾 |
| 选区与标注页面 | `src/capture/`，独立入口 `capture.html` | 选区交互、工具栏、标注编辑、扁平化导出 |
| 录屏控制条与预览 | `src/capture/`（二期） | 计时、停止、预览窗 |

依赖：`objc2-screen-capture-kit 0.3.2`（与现有 `objc2 0.6`、`objc2-app-kit 0.3` 同系列，含截图、流与录制输出绑定），无需 Swift 桥。二期视需要加入 `objc2-av-foundation`。

### 2.2 会话状态

```
截图：空闲 → 准备（收起主面板、取快照） → 选区 → 标注 → 导出 → 空闲
录屏：空闲 → 准备 → 选区 → 录制中 → 写盘收尾 → 预览 → 空闲
```

- 同一时刻只有一个会话；准备、收尾期间重复按快捷键忽略。
- 录屏快捷键按状态切换：空闲时开始，录制中则停止。
- 任一阶段 Esc 或出错都回到空闲，并销毁覆盖窗、释放快照、删除临时文件。
- 迟到的原生回调（会话已取消后到达）一律丢弃。

### 2.3 覆盖窗

- 每屏一个窗口，铺满整屏（含菜单栏和程序坞区域），不复用主面板：主面板有最小宽度、圆角、玻璃材质，“插件全屏”也只铺满可用区域。
- 采用可成为键盘焦点的非激活面板，层级高于普通窗口，加入所有 Spaces 并可浮于全屏应用之上。先验证中文输入法后再定型。
- 加载可信的本地页面 `capture.html`，使用**独立的最小 capability**（窗口标签 `capture-*`），只授予截图会话所需命令；不复制 `main` 的权限。宿主命令校验窗口身份与会话归属。
- 覆盖窗不适用“失焦即收起”；录制更不因失焦结束。

### 2.4 画面数据通道

- 冻结快照留在宿主，通过受限资源协议（如 `qingbox-capture://<会话>/<屏幕>.png`）只提供给本会话的覆盖窗，会话结束即失效。不经 JSON + Base64 反复复制。
- 导出：页面按**物理像素分辨率**把底图与标注合成为一张扁平 PNG，以二进制交给宿主写入剪贴板或文件。复制、保存、钉图、缩略图、以后的 OCR 都使用同一份扁平结果，不得输出未遮盖的原图。
- 撤销记录标注操作，不保存每一步的全屏位图。

### 2.5 坐标与色彩

- 窗口定位沿用 AppKit 逻辑坐标；捕获时换算为“屏幕局部坐标 → 物理像素 → 网页坐标”，每块屏幕按自己的缩放率换算，不假定显示器原点为正。
- SCK 输出宽高为像素，选区来源与输出尺寸分开处理。
- 一期使用 sRGB 的 SDR 色彩策略；取色值（增强版）转换为 sRGB 后输出 HEX。

### 2.6 顺序

1. 收起主面板；
2. 通过内容过滤器排除轻匣自身的窗口；
3. 逐屏取快照和窗口信息；
4. 显示覆盖窗。

异步逐屏抓取不承诺所有屏幕是同一瞬间。首次授权完成前不进行捕获。

## 3. 一期：核心截图

### 3.1 功能

| 类别 | 内容 |
| --- | --- |
| 入口 | 全局快捷键（默认 ⌥⇧A）、搜索“截图”；两者调用同一个宿主动作，不经插件加载 |
| 权限 | 首次使用时说明用途并请求屏幕录制权限；拒绝后显示打开系统设置的引导；授权后可能需要重启轻匣，界面给出提示 |
| 选区 | 冻结整屏画面；拖拽选区；悬停吸附窗口边界（按真实层叠顺序取最上层窗口），单击选整窗；单击空白处或按 ⌘A 选整屏；显示选区尺寸；拖动和拉伸调整；方向键微调 1 像素，⇧ + 方向键 10 像素 |
| 标注 | 矩形（空心）、箭头、直线（⇧ 吸附水平、垂直、45°）、画笔、文字、**步骤序号**、**马赛克（框选）**、**实色遮盖（框选）** |
| 编辑 | 标注可选中、移动、删除（⌫）、改颜色；撤销 ⌘Z、重做 ⌘⇧Z；颜色为一组常用色，粗细三档 |
| 完成 | 回车或双击：复制；⌘S：保存 PNG；Esc：取消 |

步骤序号一期做简单版：每点一下放一个圆形数字标记，编号自动递增；删除中间的标记后，其余标记自动重排。指引箭头放到增强版。

### 3.2 按键规则

- 编辑文字时，回车确认或换行，Esc 先退出文字编辑；输入法组合输入期间不响应导出。
- 未在编辑文字时：回车复制，Esc 取消整个截图。
- ⌘X、⌘C、⌘V、⌘A、⌘Z 按当前焦点对象分发；覆盖窗不会继承主面板的编辑快捷键补偿，需单独实现。

### 3.3 输出

- 复制：写入 PNG。“复制成功”与“进入剪贴板历史”分开：历史每 500 毫秒采集一次，且有 20 MB、4000 万像素上限，不承诺截图必然进入历史。不复用剪贴板历史的恢复路径。
- 保存：文件名为 `轻匣截图 2026-10-08 21.03.15.123.png`，重名时追加序号，不覆盖已有文件；保存失败时保留覆盖窗和全部标注，提示原因并可重试。
- 取消或完成后不残留覆盖窗、快照和临时文件。
- 首次使用时显示一次操作提示（拖拽选区、回车复制、Esc 取消）。

### 3.4 验收

| 项目 | 验收要点 |
| --- | --- |
| 权限 | 拒绝、到系统设置授权、重启后恢复，流程都可走通；未授权时不出现黑屏截图 |
| 会话 | 连续按快捷键不会创建多套覆盖窗；Esc、完成、出错后都完整清理 |
| 多屏 | Retina 与普通屏混用、显示器上下排列、负坐标原点，裁剪都准确；一次截一屏的行为明确 |
| 自身排除 | 截图不含轻匣主面板和覆盖窗自身 |
| 标注 | 中文输入法可正常输入文字；导出清晰度为物理像素；马赛克和遮盖在复制与保存的结果中一致 |
| 输出 | 复制后可在微信、浏览器、文档中粘贴；保存失败不丢编辑；文件名不覆盖 |
| 窗口与空间 | 在全屏应用、切换 Spaces 时不意外跳桌面，不把焦点抢回主面板；截图结束后焦点回到原应用 |

## 4. 截图增强版

放大镜、取色（C 复制色值）、椭圆、荧光笔、半透明填充、步骤序号的指引箭头、马赛克与模糊笔刷、钉图（置顶浮窗，可缩放、调透明度、双击关闭）、延时截图。

## 5. 二期：基础录屏

### 5.1 功能

| 类别 | 内容 |
| --- | --- |
| 入口 | 全局快捷键（默认 ⌥⇧R，二期上线时写入）、搜索“录屏”、菜单栏“停止录屏”保底入口 |
| 选区 | 区域、整屏：按显示器捕获并设置来源区域；窗口：使用 `desktopIndependentWindow`，被遮挡照录，最小化时画面暂停更新 |
| 选项 | 系统声音、麦克风（首次开启时才请求麦克风权限）、点击高亮（`showMouseClicks`） |
| 录制中 | 选区细边框、小控制条（计时、停止）；边框、控制条、主面板、钉图都通过内容过滤器排除，不入画 |
| 停止 | 控制条按钮、再按录屏快捷键、菜单栏入口 |
| 结束 | 写盘完成回调后打开预览窗：播放、保存 MP4、复制文件、在访达中显示 |

- 录制尺寸和音频配置在开始前固定，录制中不修改。
- 窗口模式的声音来自该窗口所属应用，可能包含该应用其他窗口的声音，选项文案如实说明。
- Info.plist 补充 `NSMicrophoneUsageDescription`。

### 5.2 收尾策略

以下情况都要正确结束文件或删除残片，并通知用户：系统停止流、被录窗口关闭、睡眠、显示器断开、磁盘已满、录制中撤销权限、退出轻匣。

### 5.3 验收

长时间录制音画同步；自身界面不入画；双音轨可在 QuickTime 与浏览器正常播放；上述异常情况都能收尾；预览与复制只在写盘完成后开放。

## 10. 待真机验证

- 非激活面板作为覆盖窗时能否稳定成为键盘焦点、支持中文输入法组合输入。
- 全屏应用上方显示覆盖窗、独立显示器空间、混合缩放下的表现。
- `SCShareableContent` 窗口列表与真实层叠顺序的对应方式。
- 授权后是否必须重启轻匣才能取得画面；新版 macOS 对屏幕录制授权的复核提示表现。
- 发布包使用稳定签名后，升级是否保留授权（当前为临时签名 `-`）。
