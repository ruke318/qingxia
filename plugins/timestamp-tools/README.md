# 时间戳

轻匣外部插件：时间戳与日期互转。只使用插件 SDK 已有能力，宿主无需改动。

## 功能

- 输入框为空时实时显示当前时间，`⌘1` / `⌘2` 直接复制当前秒级、毫秒级时间戳。
- 粘贴或输入后自动识别：
  - 时间戳按整数位数判断单位：≤10 位为秒（可带小数），11–13 位为毫秒，14–16 位为微秒，17–19 位为纳秒；支持负数。
  - 日期支持 `2024-09-28 10:25:09`、`2024/9/28`、`2024.09.28`、`2024年9月28日 10时25分09秒`、带毫秒的写法，以及带时区的 ISO 8601（如 `2024-09-28T02:25:09Z`）；未带时区的按本地时间理解，2 月 30 日这类不存在的日期会提示错误。
- 输出秒、毫秒、本地时间、UTC 时间、ISO 8601 五种结果，并显示星期与相对时间（如「3 小时前」）。
- 点击任意一行或按 `⌘1`～`⌘5` 复制对应结果；`Esc` 返回搜索。

所有计算都在插件页面内完成，不联网。

## 权限

| 权限 | 用途 |
| --- | --- |
| `clipboard.writeText` | 复制转换结果 |

## 构建与安装

在仓库根目录执行：

```sh
npm install
npm run test:timestamp    # 解析与格式化的单元测试
npm run build:timestamp   # 类型检查并构建到 dist-plugins/timestamp-tools
```

然后在轻匣中打开设置 → 插件管理 → 本地导入，选择 `dist-plugins/timestamp-tools` 目录。

浏览器回归测试随 `npm run test:browser` 一起运行（需要本机安装 Chrome，可用 `CHROME_PATH` 指定路径）。
